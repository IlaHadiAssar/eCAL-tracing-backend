# Use Jaeger UI frontend

## Context and Problem Statement
Traces need to be visualized to be able to analyse them. There are several "tracing frontends" available mostly used for distributed tracing in Microservice Architectures.

## Considered Options

* Grafana+Tempo
* Jaeger UI

## Decision Outcome

Chosen option: "Jaeger UI", because the setup is much simpler.

### Consequences

* Good, because anyone can setup a tracing frontend by simply running a docker-compose file
* Bad, because no in depth analysis possible in frontend
